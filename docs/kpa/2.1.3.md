# 奇谱发生器 2.1.3 发布日志

## 【上游】[奇谱](https://github.com/TeamZincs/kipphi)

### 新特性

#### 剥离空判定线
现在，谱面编译器在编译到 RPEJSON 时，遇到空判定线（无任何 note，每个序列最多一个半事件）将直接忽略。这将缩小 RPEJSON 体积。

### 修复与优化

#### Note 渲染时间范围反解
奇谱播放器中一直使用奇谱的 `JudgeLine.prototype.computeTimeRange(startY, endY)` 方法来计算 Note 的渲染时间范围。反解法使得渲染压力基本只取决于当前的 Note 密度，而不是总物量，但这也意味着该方法是主要的性能瓶颈。2.1.3 版本修复并优化了这个方法，使得一些边缘情况下不再出现漏渲染音符的情况，同时也提升了渲染速度。现在，奇谱播放器能够以 60fps 扛过谱面“Singularity at 2.64e+6 BPM”的峰值密度段，且在正常段 frame time 由 4ms 降至 2.5ms 左右。（测试进行于 拯救者 Y7000P，i7-14650HX，GeForce 5060，同设备上 Re:PhiEdit 几乎无法播放此谱面。）

#### 按秒计算
过去，奇谱播放器一直采用拍数本位的算法，这导致其与标准行为有所不同。现在，奇谱支持了按秒数求取事件数值。这将成为以后的默认方式。

由于通常上级能够同时提供拍数和秒数，因此不在内部计算，要求上级提供这两者。

```ts
EventNodeSequence.getValueAtBySecs(beats: number, seconds: number, timeCalculator: TimeCalculator, usePrev: boolean = false): number;
```

#### 延迟计算模板缓动的截段
由于模板缓动是可变的，应当在使用截段缓动时求解变化量，而不是在构造截段缓动时求解。况且，模板缓动和在所有事件节点序列加载后才可使用，若在构造截段缓动时求解会直接崩溃，因为此时还没有加载好模板缓动和事件节点序列之间的对应关系。

此次更新后，模板缓动在截段缓动被求值时求解左右界限值，且当左右界限值相等时返回一个0，而不是抛出错误。这需要谱师仔细检查。尽量不要在已经大量截段应用了某模板缓动的情况下修改该模板缓动所引用的事件节点序列。

```ts
class TemplateEasing extends Easing {
    ...
    override segmentedValueGetter(easingLeft: number, easingRight: number) {
        // 由于模板缓动是可变的，所以不能在分段缓动构造时预先计算几个变化量
        return (t: number) => {
            
            const leftValue = this.getValue(easingLeft);
            const rightValue =  this.getValue(easingRight);
            const timeDelta = easingRight - easingLeft;
            const delta = rightValue - leftValue;
            if (delta === 0) {
                return 0;
            }
            return (this.getValue(easingLeft + timeDelta * t) - leftValue) / delta
        };
    }
}
```

#### 修复错误的打击特效染色保存逻辑

在某个开发版本中，打击特效染色会被错误地保存为 `[0, 0, 0]`， 这导致打击特效变成黑色。如果你遇到这样的问题，请把谱面发给杨哲思修复。


#### 杂项
1. 修复了截段缓动解析的错误。先前，在遇到 RPE 的 `easingLeft` 和 `easingRight` 时，奇谱内核会产生两层嵌套的截段缓动，导致实际的缓动函数无法正确计算，产生谬以千里的渲染结果。
1. 现在当 `judgeLineGroup` 属性为空时，奇谱会设定为默认的 `["Default"]`。这使得渲染从 TPhi Editor 导出的谱面时不再因为缺少该字段而崩溃。
1. 文字事件求值器中，当文本被解读为整数时会向下取整（先前为四舍五入），解读为小数时四舍五入到千分位（之前未定义位数），与 RPE 行为保持一致。
1. 修改 RPEJSON 读取和转储时的属性名，将 `judgeSize` 改为 `judgeArea`。前者为 PhiZone Player 方言，本制谱器实现该属性时 RPE 还未计划，因此 KPAJSON 采用了 PhiZone Player 的属性名称。该改动仅影响 RPEJSON，KPAJSON 仍使用 `judgeSize`。
1. 修复了截段缓动（即带 `easingLeft` 和 `easingRight` 的事件）无法正确编译为 RPEJSON 的问题。
1. 修复了解析 RPEJSON 时不存在 X/Y 轴缩放事件时崩溃的问题。
1. 修复了编译谱面时产生带缓动的速度事件的问题。
1. 完善了关于模板缓动和截段缓动的错误处理。
1. 修复了“封装”后第一个节点不继承选中范围的求值器的问题。

## 【上游】[奇谱播放器](https://github.com/TeamZincs/kipphi-player)

### 新特性

#### 暂停键和进度条
此版本添加了暂停键和进度条UI。它们没有实际作用，只是为了更接近游玩时的界面，并且便于UI绑定等操作。

感谢 Phigrim Charting Team 的谱面《焦糖星》为UI提供了良好的测试材料！

#### 比例适配
此版本添加了完整的比例适配与分辨率调节。

实现不同的分辨率和比例只需传入对应大小的 HTML Canvas 元素。当修改画布比例时，记得调用 `useNewAspect()` 方法。

感谢 SulphurDXD 的谱面《琪露诺的算术学园》为比例适配提供了良好的测试材料！

### 修复与优化
1. 修复了 `0` 被认作假值导致不会渲染黑色打击特效的问题。
1. 对离屏画布进行 polyfill 以适配旧版本 WebKit Safari 不存在此 API 的问题。（
感谢 Master9Ray（Aax1dφ）的测试和反馈！）
1. 调整 Hold 从判定线钻出时的显示逻辑。

## 【上游】[奇谱画布编辑器](https://github.com/TeamZincs/kipphi-canvas-editor)

### 新特性

#### 剪切
原先画布编辑器并没有剪切功能。现在，(Ctrl+)X 可以“将之前的复制追认为剪切，并立即粘贴刚刚的剪切”。

注意 (Ctrl+)X 不是剪切！！！

#### 原序列粘贴
此版本支持在 [伪多线编辑](https://pgrfm.miraheze.org/wiki/Tutorial:奇谱发生器/使用伪多线编辑) 中将剪切板中的节点对/音符粘贴到其所来自的序列。需要按住Ctrl。若不按住Ctrl，则总是粘贴到当前编辑的序列。

### 修复与优化
1. 调高了贝塞尔缓动编辑器的分辨率。
1. 修正了事件节点的位置和方向，以适配 KPA 2.x 的竖版。
1. 修复 R 键放 Hold 后不能回到原始状态的问题。
1. 优化了判定线和事件层级的切换逻辑。

## 【本体】[奇谱发生器](https://github.com/TeamZincs/kipphi-apparatus)

### 新特性

#### 设为默认
现在支持将一个音符的属性设为默认，之后所有放置的音符都将继承其属性（除了朝向、类型、时间和X轴位置，这些通过侧栏控制）。

此外这次更新支持侧栏控制音符朝向。

#### 截段缓动
支持了可视化的截段缓动编辑（截段不适用于贝塞尔缓动）。截段缓动编辑器的左右边界拖动时会显示禁入区。被截段的缓动还会在原缓动下方显示缩放后的截段缓动。

#### 主动错误检查
支持在“谱面错误”次侧栏中主动触发一次全谱面错误检查。

#### 零前时间
现在编辑器可以向 0 秒 之前的时间滚动。这仅影响编辑器，不影响播放器播放的谱面。

#### 杂项
1. 适配了播放器显示轨迹的功能。
1. 添加了分辨率调节和 RPE 滚轮策略，取消原有的宽度调节（被长宽比调节取代）
1. 当 PEZ 元数据未找到时尝试查找可用的文件。
1. 限定谱面导入和创建页面的文件类型（[Issue #1](https://github.com/TeamZincs/kipphi-apparatus/issues/1)，感谢 ChenWuwei404 的建议）
1. 构建时将依赖通过 Vite 的全局替换显示在 `/about` 页面。
1. 支持在事件编辑侧栏的范围调整中指定值吸附线间隔。
1. 现在可以强制保存（虽然并没有什么用）。

#### 修复与优化
1. 修复旧版 WebKit 上出现的定位错误。
1. “拍数分母”和“音画偏移”调节移入“通用设定”次侧栏。
1. 未修改谱面时不增加写谱时间统计，现在写谱分钟数应该等于自动保存个数。
1. 伪多线状态下，当使用封装功能时，尽可能只封装当前序列。
1. 翻转事件改为成对翻转。
1. 修复了导出时的扩展名错误。
1. 修复了弹出消息被导航栏遮盖的问题。
1. 添加美观输出功能，控制保存谱面时有无缩进换行。
1. 优化错误处理。
1. 现在默认的打击特效行为为滞留，与标准行为一致。
